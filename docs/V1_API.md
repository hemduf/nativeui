# NativeUI v1 public API inventory

This document defines the normal source-stable NativeUI 1.x surface. Headers directly under `include/nativeui/` are the supported C++ surface unless a header documents a narrower debug-only contract. `nativeui/detail/*` is implementation-only and unsupported for direct consumer inclusion.

NativeUI UI objects are UI/main-thread confined unless stated otherwise. Callbacks may call documented mutation methods for the same UI domain unless an individual operation explicitly forbids reentrancy; destructive mutation during a callback is deferred by retained-tree/platform checkpoints where required. NativeUI does not promise a universal C++ binary ABI across compiler, STL, runtime, architecture, or toolchain changes.

## Stability policy

The table above is the documented normal 1.x source surface. Incompatible source or documented semantic changes require the next major version except corrections to behavior explicitly documented as undefined or erroneous. Aggregate-field additions are reviewed as source changes because positional/designated initialization can be affected.

Implementation headers under `nativeui/detail/`, internal C/C++ symbols, private native/rendering targets, generated build internals, and backend source files are not source-stable consumer API. No separate backend escape-hatch API is exported in v1.
